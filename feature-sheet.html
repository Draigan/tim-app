Asset Tracking & Team Coordination App

Map View

  • Interactive map showing all deployed assets
  • Pins color-coded by urgency
  • Available  ·  Expiring within 7 days  ·  Expired
  • Custom icons per asset type
  • Clustered pins with count badges for grouped locations
  • 8 switchable map styles (satellite, dark, streets, etc.)
  • Filter by urgency or asset type
  • Real-time search across all deployed assets
  • Fly-to animation when selecting an asset
  • "Locate Yard" button to re-center on home base
  • Map style preference saved between sessions

Inventory

  • Split view: Deployed Assets & In-Yard Assets
  • Deployed assets show address, customer, countdown timer
  • Urgency dot per deployed asset
  • In-yard assets grouped by asset type
  • Shows label, size, and notes for each asset
  • Upcoming reservation badge (within 7 days)
  • Quick-deploy button from inventory card
  • Global search across all asset fields
  • Real-time sync — updates instantly across all users

Deployment

  • Deploy any in-yard asset in a guided flow
  • Address auto-complete powered by Mapbox Geocoder
  • Coordinates captured automatically for map placement
  • Optional customer name and phone number
  • Optional expiration / scheduled pickup date
  • Optional deployment notes
  • Deployed-by staff attribution recorded automatically
  • Push notification sent to whole team on deployment
  • Active reservations auto-cleared when asset is deployed

Pickup & History

  • Pick up asset from map detail or inventory card
  • Optional pickup notes before confirming
  • Pickup-by staff attribution recorded
  • Asset returns to In-Yard inventory instantly
  • Full deployment history log Admin
  • Search by asset, customer, or address
  • Filter by status, asset type, and date range
  • Shows who deployed and who picked up
  • Duration in days calculated automatically
  • Paginated — 50 records per page

Team Chat

  • Real-time group chat for the whole team
  • Own messages right-aligned, others left-aligned
  • Sender name shown for first message in a sequence
  • Relative timestamps (just now, 5m, 2h, etc.)
  • Paginated history — "Load older messages" button
  • Auto-scrolls to latest message on open
  • Unread indicator dot on chat tab when new messages arrive
  • Chat marked as read automatically when tab is open

Push Notifications

  • Web Push — works on mobile and desktop browsers
  • Deployment alert: asset label + address sent to team
  • Chat alert: sender name + message preview
  • Tapping a notification navigates to the relevant page
  • Enable / disable anytime from Settings
  • Respects browser permission status
  • Sender is excluded from their own notifications

Calendar Admin

  • Month view and week view (preference saved)
  • Create, edit, and delete custom events
  • 9 colour options per event
  • Optional time field and multi-day date ranges
  • Asset reservations appear as dots on the calendar automatically
  • Click a reservation dot to jump to the asset detail
  • "Today" button and previous / next period navigation
  • Selected-day panel lists all events and reservations

Reservations Admin

  • Reserve any in-yard asset for a future date range
  • Enter customer name and address at time of booking
  • Inventory shows upcoming reservation badge within 7 days
  • Reservation dot appears on calendar on the start date
  • Auto-deleted when the asset is deployed on or after start date
  • Reserve button visible to admins only

Asset Manager Admin

  • Create new assets (type, icon, label, optional size)
  • Delete assets — blocked if currently deployed
  • Create and delete custom asset types
  • Choose icon from built-in library for each type
  • All assets listed with deployed vs. in-yard status

User Management Admin

  • Invite new staff members with name and email
  • Temporary password generated on account creation
  • Password rules enforced: min 5 chars, 1 uppercase, 1 number
  • Delete user accounts with name-confirmation dialog
  • Managed entirely from the Settings page

Settings

  • Dark / Light mode toggle
  • Text size: Small, Medium, Large, XL
  • Enable / Disable push notifications
  • In-app feedback submission
  • Shows signed-in user name & email
  • Sign out

PWA & Mobile

  • Installable on iOS and Android home screen
  • Service worker for offline support
  • Mobile-first, touch-optimized UI
  • Safe-area padding for notches and home bars
  • Pinch-to-zoom on the map
  • Responsive across all screen sizes

Real-Time Sync

  • All data syncs instantly across every session
  • Live: deployments, assets, asset types
  • Live: reservations, calendar events, chat
  • No refresh needed — changes appear automatically
  • Powered by Supabase real-time subscriptions
